# Savora Restaurant Owner Mockup Design

## Goal

Create eleven high-fidelity desktop website mockups for the Savora restaurant-owner portal. The mockups must use English UI copy, share the existing Customer experience's visual language, and present operational restaurant data with a clear, professional hierarchy.

## Shared visual system

- Canvas: desktop web app, 16:10 landscape.
- Shell: persistent dark-forest left sidebar, light ivory workspace, compact top utility bar.
- Primary: `#073B2B`.
- Header and hover: `#04291E`.
- CTA and location accent: `#EF634B`.
- Page background: `#FBF9F3`.
- Secondary surface: `#E8EDDF`.
- Primary text: `#1C2923`.
- Secondary text: `#657169`.
- Border: `#DFE4DA`.
- Accessibility focus: `#1B75D0`.
- Components: rounded cards, restrained shadows, compact status chips, accessible form controls, data tables, filters, charts, and confirmation panels.
- Typography: modern sans-serif with strong headings and readable operational data.
- Brand continuity: retain Savora's existing Customer UI character through the forest-green/ivory palette, coral actions, soft rounded surfaces, and generous spacing.

## Navigation

The sidebar groups the eleven screens into eight navigation areas:

1. Overview
2. Orders
   - Live Orders
   - Order History
3. Menu
   - Menu Management
   - Add/Edit Item (contextual child screen)
4. Storefront
   - Store Profile
   - Operations & Hours
5. Finance
   - Revenue & Payouts
   - Invoices & Statements
6. Analytics
7. Reviews

## Required interactions represented visually

- Live orders move through pending, accepted, preparing, and ready-for-pickup states.
- Menu availability affects the Customer catalog and checkout.
- Store profile and operating hours affect Customer discovery and ordering availability.
- Restaurant address supports both `Use current location` and manual entry.
- Completed and refunded orders feed financial summaries, invoices, analytics, and reviews.
- Notifications, search, filtering, empty/error states, and clear primary actions are represented where relevant.

## Output

- Eleven separate high-fidelity PNG mockups.
- Consistent desktop dimensions and shared shell.
- No watermark.
- English UI copy only.
