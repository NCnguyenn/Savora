# Savora Restaurant Owner Mockup Prompt Set

## Shared prompt

Create a high-fidelity, shippable Savora restaurant-owner desktop web UI at
1536×1024. Reuse the existing Customer experience's warm ivory, deep
forest-green, coral accent, rounded-card, generous-spacing visual language,
adapted to a professional operations portal with a persistent left sidebar and
compact top utility bar.

Use English UI copy only. Use `#073B2B` primary, `#04291E` dark,
`#EF634B` coral, `#FBF9F3` ivory, `#E8EDDF` sage, `#1C2923` primary text,
`#657169` secondary text, `#DFE4DA` borders, and `#1B75D0` accessibility
focus. Use readable typography, consistent icons, rounded 12px cards,
restrained shadows, accessible controls, and practical data density. Do not
use perspective, device frames, watermarks, gradients, concept-art styling, or
a dark main canvas.

## Page prompts

1. **Restaurant Overview** — KPIs, revenue/order chart, live queue, top menu
   items, and low-stock alert.
2. **Live Order Center** — status counters, filtered live queue, selected-order
   detail, preparation time, reject, and accept actions.
3. **Order History** — summary metrics, date/search filters, audit table,
   timeline, item details, invoice, and reorder actions.
4. **Menu Management** — category and availability filters, food-card grid,
   stock states, availability toggles, category management, and add-item CTA.
5. **Add/Edit Menu Item** — item information, photo, price, option groups,
   availability, dietary tags, publishing checklist, and Customer preview.
6. **Store Profile** — branding, Customer-facing details, current-location and
   manual-address methods, map pin, delivery settings, and Customer preview.
7. **Operations & Opening Hours** — open status, weekly schedule, special
   hours, capacity safeguards, fulfillment settings, and Customer status
   preview.
8. **Revenue & Payouts** — sales/fees/refunds KPIs, revenue chart, next payout,
   transactions, payout account, and fund-availability note.
9. **Invoices & Statements** — document categories, invoice table, status and
   download actions, invoice preview, PDF/print actions, and retention note.
10. **Business Analytics** — sales/order chart, status donut, ordering-time
    heatmap, menu performance, kitchen performance, and demand opportunity.
11. **Ratings & Feedback** — rating summary and distribution, verified-review
    list, filters, order context, public reply composer, and feedback insights.

Generated with the built-in ImageGen workflow using the existing Customer
screens and the first approved Restaurant Overview mockup as visual references.
